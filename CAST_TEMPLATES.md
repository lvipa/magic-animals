# Milo и друзья — шаблоны для моделирования

01.10.2026 по запросу пользователя созданы семь оригинальных листов
встроенным ImageGen. Общий референс — утверждённый образ Milo; все герои
имеют крупную голову, выразительные глаза, короткие лапы и тканевые худи.

| Foxy | FOX | острая мягкая мордочка, большие ушки, пушистый хвост | шалфейное худи |
| Bubbles | DOG | широкая мордочка, висячие ушки, завиток хвоста | голубое худи |

Имена и идентификаторы сохранены из существующего каталога игры.
Foxy и Pebble получили вторую версию: у лисы уточнена A-поза, у панды
исправлены сплошные тканевые рукава. Первая версия остаётся для сравнения;
в галерею и ZIP входят выбранные вторые версии.

## Файлы

- `assets/characters/cast/concepts/`: исходные PNG 1536×1024, запросы
  `prompts-v1.json`, SHA-256 выбранных файлов `sha256-v1.json`.
- `assets/characters/cast/templates-manifest.json`: видовые признаки,
  общие правила, имена, игровые ID и требования к будущим GLB.
- `public/review/cast-templates/`: отдельная галерея восьми героев, включая
  оригинальный лист Milo, полноразмерные PNG и общий ZIP около 17,7 МБ.

Сборка из корня проекта:

```powershell
node scripts/build-cast-template-gallery.mjs
python scripts/package-cast-templates.py
```

## Как использовать

Это иллюстрированные листы для построения объёма и проверки общего стиля.
Они не являются готовыми мешами, UV-картами или калиброванными фотографиями.
У каждого листа три вида; перед реконструкцией нужно согласовать между
ними форму, размеры, положение хвоста и деталей одежды. Боковая проекция
может скрывать вторую руку. У Milo основной turnaround имеет руки вниз;
отдельный `milo-rig-pose-v1.png` задаёт A-позу. Не смешивать эти позы во входах
одной реконструкции без подготовки.

В Blender разместить виды как reference images, выстроить общую сетку,
глаза, одежду, UV и материалы по системе CAT. Для image-to-3D с одним
изображением использовать полный отдельный фронтальный или трёхчетвертной
вид одного героя; весь лист из трёх фигур не подавать как один предмет.

Точный текст запросов сохранён, но повторный вызов ImageGen может дать
другой результат; PNG и их хеши фиксируют выбранные версии.

## Общая 3D-система

CAT v8 имеет 21 кость, отдельные глаза, веки, связанный рот, короткую шерсть
и семь клипов. Пользователь разрешил обновить остальных героев. Общая игровая
коллекция и воспроизводимые скрипты описаны в [MILO_CAST_RELEASE.md](MILO_CAST_RELEASE.md).
Оригинальные иллюстрированные листы остаются референсами, а не мешами.

Веб-проверка галереи: 1280 и 390 пикселей, все восемь изображений
загружаются, горизонтального переполнения и ошибок JavaScript нет,
ZIP доступен. Физические тесты устройств остаются отдельным этапом.

Галерея опубликована на ISP в отдельной папке; все 12 файлов проверены
через HTTPS по SHA-256. Браузерная проверка на опубликованном адресе
также прошла при 1280 и 390 пикселях. Снимки ISP до и после совпали
для доменов, DNS, сертификатов, настроек соседних сайтов и их основных
файлов. Эта ранняя публикация касалась только шаблонов. Последующий игровой перенос описан в MILO_CAST_RELEASE.md.
