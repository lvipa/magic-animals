# Инструкция запуска

## Пользователю

1. Откройте https://animals.flowlabli.online/ в Safari на iPad/iPhone или Chrome/Edge.
2. [Скачайте лист A4](https://animals.flowlabli.online/printables/magic-animals-a4.pdf).
   Печатайте **A4, вертикально, 100% / Actual size**, без «вписать в страницу».
3. Вырежьте три карточки с полной рамкой и узором. Положите одну на ровную поверхность.
4. Нажмите **PLAY** и разрешите камеру. Покажите карточку целиком с расстояния примерно
   20–40 см при ровном освещении. Если камера недоступна, выберите игру без камеры.
5. На `/friends` выбирайте друга и движения. Кнопки **Listen & find a friend** и
   **Listen & choose a move** предлагают задание на слух. **Hear again** повторяет
   вопрос, неправильный выбор вызывает мягкую подсказку, правильный — похвалу.
6. Для TV откройте `/tv` на телевизоре, нажмите **START TV**. Сканируйте QR обычной
   камерой телефона, откройте ссылку и нажмите **Connect TV**. Для ручного ввода
   на телефоне есть `/connect-tv` и кнопка подключения на стартовом экране игры.
7. На TV нажмите **Enable sound**, если голос должен звучать на телевизоре; затем
   выберите **Speak on TV** на телефоне. Одновременно говорит только один экран.
8. Выход из полноэкранного режима — кнопкой fullscreen или **Esc** на компьютере.

В игре нет регистрации и пароля. Шестизначный TV-код нужен только для сопряжения
конкретного телевизора и телефона. Офлайн работает одиночная игра после загрузки
PWA и всех ассетов; TV требует сети между устройствами.

## Разработчику

Установите Node.js 24 LTS. В каталоге проекта:

```sh
npm ci
npm run dev
```

Vite печатает точный адрес/порт в терминале. Для просмотра с телефона используйте
доступный сетевой адрес компьютера и HTTPS. Открытие `127.0.0.1` на телефоне не
откроет приложение с компьютера.

```sh
npm run lint
npm test -- --maxWorkers=1 --no-file-parallelism
npm run build
npm run preview
```

Для локального TV вместо preview: `npm run tv`. Он обслуживает `dist/` и WebSocket
на одном порту 8080. Нужен доступный обоим устройствам адрес; production — HTTPS.

## Пересборка ассетов

Обычный запуск не требует Blender, Python или модели голоса.

```sh
# Только если изменили оригиналы карточек:
npm run cards
npm run targets
npm run test:tracking

# CAT: экспорт текущего сохранённого Blender-источника:
blender --background assets/characters/cat/milo-master.blend --python scripts/export-cat-master.py
npm run build
python scripts/check-cat-studio.py
```

`build-cat-master.py` используется только для создания начального источника и
перезаписывает `.blend`. После ручных правок используйте экспорт сохранённого
файла выше. Подробнее: [CAT_PRODUCTION.md](CAT_PRODUCTION.md).

Для озвучки: создайте Python окружение `.voice-tools`, установите зависимости из
`scripts/voice-requirements.txt`, скачайте веса командой
`python scripts/download-voice-model.py`, затем последовательно запустите
`scripts/expand-audio-lines.py`, `scripts/generate-neural-audio.py` и
`scripts/generate-cast-calls.py` этим Python. Модель нужна только разработчику.

PDF/ZIP пересобирает `python scripts/package-printables.py` (нужен `reportlab`).
Любое изменение target-картинки требует повторной компиляции `.mind`; нельзя
подменять только изображение в печатном наборе.

## Публикация

Содержимое `dist/` публикуется целиком в корень отдельного HTTPS-сайта. Настройте
SPA fallback на `index.html`, а отсутствующим файлам audio/markers/models оставьте
404. Для статического хостинга TV нужен отдельный relay; один HTML его не заменяет.
В ISP используйте отдельный поддомен и каталог, не изменяя чужие сайты и сертификаты.
Подробности и пример reverse proxy: [DEPLOYMENT.md](DEPLOYMENT.md).

В GitHub коммитятся исходники и подготовленные ассеты; `dist`, веса Kokoro,
локальные настройки хостинга и доступы не коммитятся.
