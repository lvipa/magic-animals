# CAT: архив предыдущего источника и экспорта

**Актуальный игровой CAT — присланный Milo с короткой шерстью, 21 костью и
семью клипами.** Источник и экспорт: [MILO_AR_RELEASE.md](MILO_AR_RELEASE.md).
Далее сохранено описание прежней версии; не используйте её экспорт для
перезаписи текущей поставки.

## Что изменилось

Прежняя сборка из 79 самостоятельных поверхностей больше не используется.
Состояние до изменений и решение описаны в [CAT_PIPELINE_REVIEW.md](CAT_PIPELINE_REVIEW.md).

Текущий источник: `assets/characters/cat/milo-master.blend`.
В нём сохранены редактируемые контрольные сетки и модификаторы:

- `CAT_BodyConnected`: связный череп, объёмная мордочка, шея, тело, уши,
  руки с лапами, разветвление таза на ноги и задние лапы;
- `CAT_HoodieSewn`: рукава соединены с плечами общей сеткой, отверстия у
  горловины/запястий/нижнего края, модификатор толщины ткани;
- `CAT_HoodOpenShell`: открытая оболочка капюшона, глубина за черепом,
  отдельная подкладка на внутренней стороне;
- `CAT_TailChain`: плавно сужающийся хвост с пятью сегментами деформации;
- отдельные материалы глаз, носа, внутреннего уха, ткани, шерсти и подушечек;
- UV, directional normal/roughness maps, fleece maps и radial iris map;
- 33 кости, нормализованные веса, 7 NLA clips.

Контрольные клетки созданы алгоритмически через явные вершины и quad patches.
Это не скульпт, сделанный художником вручную. Соединённая топология и реальная
одежда устраняют прежнюю конструкцию из примитивов, но сами по себе не
подтверждают художественный уровень референса.

## Рабочий процесс художника

1. Открыть `milo-master.blend` в Blender 4.5 LTS.
2. Править контрольную сетку в Edit/Sculpt mode; смотреть модификаторы
   Subdivision и Solidify, силуэт и тканевые складки со всех сторон.
3. Проверять веса в Weight Paint и деформацию в Pose mode.
4. В NLA Editor включать по одному действию: idle, happy, wave, jump, run,
   sleep, roar. Остальные tracks должны быть muted при просмотре одного клипа.
5. Сохранить `.blend`. Экспортировать **сохранённый источник**, без пересборки:

```powershell
blender --background assets/characters/cat/milo-master.blend --python scripts/export-cat-master.py
npm run build
python scripts/check-cat-studio.py
```

Экспорт работает с сохранённой геометрией/UV/материалами/rig/клипами. Он
применяет модификаторы только в памяти, оптимизирует web mesh, ограничивает
веса четырьмя влияниями, объединяет совместимые детали по материалу и
экспортирует GLB с Draco. Исходник не перезаписывается.

`scripts/build-cat-master.py` создаёт начальный контрольный ассет с нуля и
**перезаписывает исходник**. После ручной доработки запускать его нельзя без
сохранения отдельной копии. Старое имя `build-cat-studio.py` — только alias
этого нового генератора. Прежний prototype хранится в `assets/characters/cat/legacy`.

## Runtime

`GLTFLoader → Draco → SkeletonUtils.clone → SkinnedMesh → AnimationMixer`.
Одна модель, самостоятельный rig/mixer для каждого экземпляра; геометрия и
текстуры разделяются. Нельзя возвращать примитивный CAT при ошибке загрузки:
ошибка явно показана в галерее. UI и OrbitControls сохранены.

Единая сетка тела сохраняет прежнее появление paws → head → body:
материал экземпляра получает маску по rest-space координатам. Клоны владеют
этими материалами и освобождают их; исходные geometry/textures остаются в кэше.

`public/models/cat.glb` — тот же GLB, что `cat-studio.glb`, для существующей
ссылки Download. `npm run models` не пересоздаёт CAT из `toyFactory.ts`.
Остальные семь животных остаются прототипами до утверждения CAT.

## Проверки

```powershell
blender --background --factory-startup --python scripts/review-cat-master.py
```

Скрипт импортирует именно экспортированный GLB и создаёт рендеры в
`artifacts/cat-master-review`: 0/45/90/135/180/225/270/315°, все действия,
дополнительные фазы Jump/Run/Sleep. Камера и кадрирование фиксированы.
Это Cycles-проверка формы и деформации, не доказательство WebGL-качества/FPS.
Фактический WebGL просматривается отдельно в `/friends`.

[CAT_REVIEW.md](CAT_REVIEW.md) содержит разбор оставшихся недостатков.
[Обзор WebGL](https://animals.flowlabli.online/review/cat-master/index.html) показывает
восемь направлений, все clips и дополнительные фазы. `/__cat-review` — только
development route для воспроизводимой проверки; он исключён из production.
Статические review-снимки не входят в PWA precache.

`cat-master-info.json` хранит бюджет/связность/состояние approval; эти данные
не являются автоматическим заключением о красоте модели. Полное утверждение
требует визуального просмотра, проверки взаимодействий поверхности и
согласия пользователя. FPS на физических мобильных устройствах ещё не измерен.

До утверждения запрещена массовая адаптация других видов. После него
переиспользуются контракт rig, материальные принципы, глаза, шерсть, одежда,
lighting и animation controller, но каждому виду моделируется своя анатомия.
