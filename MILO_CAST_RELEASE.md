## Общий процесс

`scripts/build-cast-game.py` импортирует оригиналы, сохраняет UV/рисунок одежды,
связывает кожу с тем же набором 21 кости, ограничивает влияние четырьмя костями
на вершину и закрепляет центральную молнию на корпусе. Отдельные глаза
сохраняют исходный рисунок радужки. Веки следуют поверхности лица и имеют
промежуточные морфы и складку закрытого глаза. Для шести новых героев есть
связанный рот с полостью и языком. У слонёнка используется мягкое движение
нижней части морды; отдельная полость за хоботом не строится.

`cast_face.py`, `cast_animation.py`, `cast_fur.py` используют способы Milo:
матовые PBR-поверхности, отражающие глаза, семь NLA-клипов и короткие
alpha-MASK пряди с перенесёнными весами кожи. В одном персонаже отображается
только HIGH (1200 лент) либо LOW (420). Это лёгкая стилизация шерсти,
а не физическая симуляция волос. Одежда уже моделирована в исходных GLB.

Все герои имеют ground=0, высоту 1.15, одинаковые имена основных костей,
`idle / happy / wave / jump / run / sleep / roar`, встроенные карты до 1024²,
Draco и файл менее 8 МБ. Видовые пропорции и ориентиры лица различаются.
Уши/хобот пока следуют голове, без отдельных цепочек костей.

## Запуск и восстановление

Обычный запуск игры описан в RUN_GUIDE.md. В GitHub входят игровые GLB,
исходники приложения, скрипты Blender и метаданные происхождения. Исходные
присланные GLB и редактируемые локальные сцены находятся в игнорируемой
`.deployment/incoming-cast/`; они не содержат секретов, но не входят в Git.
Чтобы изменить опубликованный персонаж без этой папки, импортировать его
актуальный GLB из `public/models/` в Blender: он содержит rig, UV, материалы,
морфы и клипы. Для точного повторного построения нужны оригинальные файлы,
перечисленные в `assets/characters/cast/incoming-models.inventory.json`.

```powershell
blender --background --python scripts/build-cast-game.py
node scripts/catalog-cast.mjs
npm run build
python scripts/check-cast-assets.py
node scripts/check-cast-runtime.mjs
```

Можно передать после `--` один ID, например `-- dog`.
`npm run models` только проверяет и каталогизирует готовые GLB, не заменяет
их процедурными моделями. Текущие имена и SHA-256 — в `public/models/catalog.json`.

## Загрузка и публикация

Общий загрузчик кэширует неизменяемую геометрию/карты и создаёт отдельные
скелет, mixer и reveal-материалы для каждого экземпляра. Не более двух
ассетов загружаются одновременно; галерея/игра/TV обновляют экземпляр после
декодирования. AR загружает модель при первом распознавании её карточки
и проверяет, что камера ещё открыта, прежде чем создавать скелет.

Хешированные URL предотвращают подмену нового персонажа старым PWA-файлом.
В precache включены только актуальные восемь GLB из каталога. Старые версии
на ISP сохраняются для уже открытых старых клиентов. Интерфейс, карточки
Milo v2, QR/TV-код и английские игры продолжают использовать прежние ID.

## Ограничения и следующая работа

Это общий игровой выпуск, а не заявление об окончательной художественной
приёмке. Остались полировка весов одежды и отдельных поз, стыков век,
силуэта гривы/макушки, отдельные контроллеры ушей/хобота и артикуляция речи.
Maple требует оценки цвета мордочки; его происхождение из PANDA явно указано.
Проверка WebGL на компьютере не заменяет измерения FPS/памяти на iPhone/iPad
и реальном телевизоре. Полный offline-набор стал больше; установка должна
успеть завершить скачивание перед запуском без сети.

## Проверки

- TypeScript, ESLint, production/PWA build; 24 теста приложения.
- `check-cast-assets.py`: восемь GLB, 21 кость в каждом, реальные разные
  каналы семи клипов, лицевые морфы, нормализованный skin и два уровня ворса.
- `check-cast-runtime.mjs`: настоящий GLTFLoader/Draco/WebGL, движение
  поверхности кисти и костей ступней, ground/height, 32 кадра поз всех героев.
- `check-ar-roster.mjs`: восемь карточек в произвольном порядке в настоящем
  MindAR через синтетический MediaStream при 390×844.
- `browser-test.mjs`: 16 проверок, история CAT→DOG→LION, финал, отказ камеры,
  Free Play, освобождение stream и offline-перезапуск через Service Worker.
- `test-tv.mjs`: 14 проверок, два браузера и настоящий relay, вся коллекция,
  повторное соединение и декодирование 104 звуков.

Снимки и отчёты — в игнорируемой `.test-artifacts/`. Исходный CAT v8
проверяется отдельно `check-cat-studio.py` и сохранён побайтно.
Размер всех игровых GLB — около 51 МБ, полного precache — около 71 МБ.
