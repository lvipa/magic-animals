# Camera privacy

Magic Animals использует камеру только для распознавания трёх бумажных карточек на устройстве.

- Video frames идут в локальный MindAR/TensorFlow.js pipeline и локальный Worker.
- Нет отправки camera frames на сервер, cloud vision или удалённого inference.
- Нет фото, записей видео, MediaRecorder или сохранения изображения ребёнка.
- Нет face recognition, face tracking или идентификации человека.
- Микрофон не запрашивается: `getUserMedia({ audio: false, video: ... })`.
- Нет аналитики, рекламы, трекеров и аккаунтов.
- При выходе из game/diagnostic camera tracks прекращаются.

В одиночном режиме из сети загружаются собственные static files того же origin: JS/CSS, карточки, targets.mind, иконки и записанная озвучка. Camera Mode тоже использует исключительно локальное video, а 3D Mode не использует камеру.

При подключении TV используется WebSocket того же origin (локальный Node relay) или POST polling того же origin (публичный PHP relay). Передаются состояние сцены, ID животных/звуков, таймеры, pairing code и capability tokens. Кадры камеры и запись звука не передаются. Сессии находятся в RAM Node либо приватном JSON state PHP вне web root; IP временно используется для ограничения попыток подключения. Code/role/token сохраняются в sessionStorage вкладки; Disconnect удаляет их. Для публичного сайта используется HTTPS. QR генерируется локально из адреса подключения и временного кода; сторонних QR сервисов нет. Голос синтезирован заранее; во время игры нет запросов к внешнему TTS. Задания на слух не требуют аккаунта и не отправляют результаты на сервер.

localStorage содержит только completed, available animal IDs, quality и volume. Camera frames, имена, возраст, фотографии и биометрические данные не записываются. Service Worker кэширует static game resources; он не кэширует camera stream.

Кнопка RESET GAME сбрасывает прогресс и доступных животных, сохраняя взрослые настройки качества/громкости. Полное удаление всех локальных данных возможно через настройки сайта Safari. Обычные журналы доступа самого hosting контролируются владельцем hosting; приложение не передаёт туда camera content.

Браузерный тест проекта использует только искусственно сформированное видео из наших PNG-карточек. Это не пользовательская камера и не изображение ребёнка.
