# Обновление и загрузка моделей

## Причина задержек

Ранее Service Worker включал все восемь GLB в обязательную установку: около
51 МБ моделей и около 20 МБ остальных файлов. Пока новый набор не скачивался
целиком, обычный браузер продолжал выдавать старый index из установленного
кэша. Приватный режим начинал с пустого кэша и сразу запрашивал новый HTML.
Начальное открытие интерфейса также ожидало загрузки CAT, даже на `/friends`.

## Изменения

- Интерфейс открывается сразу; выбранный герой загружается отдельно.
- Не более двух скачиваний одновременно; общий Draco decoder с одним worker.
  Выбранный герой получает приоритет перед ожидающими героями общей галереи.
- Статусы очереди, скачивания с процентом, декодирования и ошибки. Повтор
  очищает неудачный Promise, поэтому не требует перезагрузки страницы.
  При ошибке декодирования удаляется только повреждённый файл GLB, чтобы повтор
  не возвращал те же некорректные байты из кэша.
- Тайм-аут скачивания 60 секунд; медленное/оборванное соединение даёт повтор.
- GLB исключены из precache. Хешированные URL используют CacheFirst в
  `animals-models-v1`; установка SW уменьшена примерно с 71 до 20 МБ.
- HTML навигации использует NetworkFirst с тайм-аутом 3 секунды и offline
  fallback. Корень `/` не перехватывается directoryIndex precache-маршрутом.
- Проверка SW при открытии, возвращении во вкладку, восстановлении сети и
  каждые 60 секунд. Смена контроллера обновляет открытую страницу один раз.
- Все друзья для игры без интернета: `/offline-status`, кнопка **Save all
  friends for offline play**, дождаться READY всех групп. Проверка учитывает
  precache и runtime cache, а не только precache.

## Обновление старого Safari без удаления прогресса

Открыть https://animals.flowlabli.online/review/update.html в обычном браузере
и нажать **Update and open friends**. Страница находится вне старого
navigation fallback (`/review/`), получает актуальный SW с `updateViaCache:
none`, ждёт активации и открывает галерею. LocalStorage, TV-код, сохранённая
игра и остальные сайты не очищаются. Требуется интернет и свободное место.

## Проверки

`node scripts/check-pwa-update.mjs`: настоящий предыдущий production SW,
сохранённый профиль Chrome, установка новой версии при заблокированных GLB,
повтор после ошибки, прогресс Ellie, свежий HTML при активном SW и offline
reload скачанного персонажа. Байты GLB старой установки заменены маленькими
непрозрачными ответами только в тестовом сервере для ускорения фикстуры.
`--recovery` проверяет переход через отдельную страницу обновления. Предыдущий
выпуск сохраняется перед публикацией в `.test-artifacts/pwa-update/previous`.
Для запуска в другом checkout нужен этот каталог (`OLD_RELEASE_DIR`) или
URL предыдущей сборки (`PREVIOUS_RELEASE_URL`); текущая сборка не заменяет
старую фикстуру.
`node scripts/browser-test.mjs`: реальный MindAR, история, сохранение всех
друзей и offline reload. `node scripts/check-cast-runtime.mjs`: настоящий
декодер, кожа и позы всей коллекции. На физическом iPhone нужно отдельно
проверить память и первый запуск на медленном соединении.
