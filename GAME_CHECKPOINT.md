## Как вернуться к игре

**Чтобы играть:** https://animals.flowlabli.online/.
Карточки для печати: `/printables/magic-animals-milo-a4.pdf` (A4, 100%).
На TV открыть `/tv`, нажать START TV, на телефоне отсканировать QR или ввести
шестизначный код на `/connect-tv`. См. [TV_GUIDE.md](TV_GUIDE.md).

**Статус сайта на 04.10.2026:** `/`, `/friends` и `/tv` возвращают HTTP 403
со страницей хостинга «Работа сайта приостановлена». Причина приостановки не установлена.
Предыдущая публикация 02.10.2026 была проверена по HTTPS; текущая недоступность
не означает потерю исходников. Для возвращения к онлайн-игре сначала требуется
восстановить доступность хостинга. Настройки ISP в рамках сохранения не менялись.

**Чтобы продолжить на этом компьютере:** открыть Codex → выбрать папку
`C:\Work\Codex\KidsGame` → открыть этот чат или создать новый и вставить текст ниже.
Открыть текущую папку можно без переключения Git и без повторного скачивания моделей.

```text
Продолжаем Magic Animals из C:\Work\Codex\KidsGame.
Прочитай GAME_CHECKPOINT.md, GAME_CHECKPOINT.json, NEXT_GAMES_PLAN.md,
README.md, CHILD_PLAY_RELEASE.md и ARCHITECTURE.md.
Проверь git status и изменения после тега magic-animals-snapshot-2026-10-04.
Базовый игровой код — 35dc86b. Сначала кратко восстанови состояние,
затем выполни моё новое задание. Сохраняй общий стиль Milo, AR-карточки,
TV QR/код и безопасность публикации. Старые записи об отклонённых CAT-этюдах
в FUTURE_WORK_HANDOFF.md являются историей, а не текущим заданием.
```

**Чтобы восстановить точную версию на другом компьютере:** нужен Node.js 24 LTS.
Создать отдельную папку:

```sh
git clone --branch magic-animals-snapshot-2026-10-04 --single-branch https://github.com/lvipa/magic-animals.git magic-animals-snapshot
cd magic-animals-snapshot
npm ci
npm run dev
```

Для новой работы в этой копии создать ветку: `git switch -c continue-magic-animals`.
Для production/PWA: `npm run build`, затем `npm run preview`.
Для локального TV: после build — `npm run tv`, порт 8080.
Телефону нужна доверенная HTTPS-ссылка; его `localhost` не является компьютером.
Подробнее: [RUN_GUIDE.md](RUN_GUIDE.md).

Архив исходников можно распаковать в новую папку и выполнить `npm ci` / `npm run dev`.
Для художественного редактирования действующих моделей дополнительно сохранять
локальные Blender-сцены из `.deployment/incoming-milo/` и `.deployment/cast-polish/`.
Их наличие и пути описаны в документах поставки; GitHub-копии достаточно для запуска
готовой игры. Локальные доступы к инфраструктуре передаются отдельно и приватно.

## Что сохранено

- Восемь друзей Milo: CAT, FOX, DOG, LION, RABBIT, BEAR, PANDA, ELEPHANT.
- Восемь карточек Milo v2, PDF и редактируемые печатные исходники.
- `/hunt`: любой порядок карточек, альбом друзей, задания и звёзды, перезапуск
  в любой момент; оба счётчика показывают прогресс текущего раунда.
- `/friends`: движения и эмоции, фразы, повтор озвучки, задания на слух, рассказы друзей.
- Полянка, лес, космос, батуты; выбранный мир сохраняется.
- Детское нижнее меню; QR/код TV; PWA и загрузка друзей для офлайн-игры.
- Общая система GLB/rig/PBR, 202 записи; исправления хвоста/рта FOX и DOG.
- Исправлено накопление поворота головы; переходы между действиями сглаживаются
  общей системой `src/characters/poseLayer.ts`.
