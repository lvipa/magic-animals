## TV и мультяшный звук (тест отложен пользователем)

- [ ] TV браузер открывает `/tv`, пульт выбирает START TV, появляется код.
- [ ] iPad подключается через Parent Mode → Connect TV по доверенному HTTPS/WSS.
- [ ] Голос Foxy приятный, CAT/DOG/LION понятны; громкость комфортна на обоих устройствах.
- [ ] Speak on iPad / Speak on TV меняет источник без одновременного воспроизведения.
- [ ] После reload TV: сцена восстановлена, Enable sound разблокирует голос.
- [ ] Передача через портал, потеря Wi-Fi и фон не теряют животное.
- [ ] Финал показывает всех друзей; несколько повторов не накапливают память.

## Старт и установка

- [ ] URL открыт именно в Safari, доверенный HTTPS, без certificate warning.
- [ ] Welcome: Foxy виден, PLAY большой и не обрезан.
- [ ] Landscape: safe-area, кнопки и video без растяжения.
- [ ] Portrait: нет горизонтального скролла; ребёнок всё ещё может играть.
- [ ] PLAY вызывает permission; rear camera появляется после Allow.
- [ ] Deny → Foxy → PLAY WITHOUT CAMERA → 3D игра продолжается.
- [ ] Разрешение можно изменить в Safari settings; повторный запуск снова пробует AR.
- [ ] Share → Add to Home Screen → Add; правильная иконка и имя.
- [ ] Home Screen: standalone, нет обычной браузерной панели.
- [ ] PWA relaunch: Welcome, saved completed/available/quality/volume восстановлены.

## Камера / AR

- [ ] `/camera-test`: READY, разумное разрешение, ориентация и camera FPS.
- [ ] При наличии нескольких камер доступно переключение; старая camera track прекращается.
- [ ] `/marker-test`: camera READY, tracking READY.
- [ ] Физическая CAT даёт target CAT, YES, cube и оси в нужном месте.
- [ ] Физическая DOG даёт DOG, не CAT.
- [ ] Физическая LION даёт LION, не другие цели.
- [ ] Уберите цель: visibility NO; объект выдерживает краткую потерю, затем скрывается.
- [ ] Верните цель: pose восстанавливается, найденное животное не теряет звезду.
- [ ] Цель уже показана во время intro: после запроса оно всё равно появляется.
- [ ] Повторный вход в marker test / игру несколько раз не оставляет старую камеру.
- [ ] Карточки на 20, 30, 40, 60 см; зафиксировать рабочий диапазон.
- [ ] Низкий свет / яркий свет / умеренный наклон; записать пределы.
- [ ] Нет ложного распознавания одного животного вместо другого.

## Звук / история

- [ ] После одного PLAY все записанные реплики звучат без дополнительных тапов.
- [ ] Hello, intro, Find the CAT/DOG/LION понятны и имеют комфортный уровень.
- [ ] CAT: свет → лапки → голова → выход; CAT / A cat / meow.
- [ ] Касание персонажа меняет реакцию и не мешает автоматическому продолжению.
- [ ] DOG: появление, короткий бег, падение Foxy, возвращение.
- [ ] Baby lion добрый; roar не пугает ребёнка.
- [ ] CAT → DOG → LION; три звезды; no game-over/negative feedback.
- [ ] Финал сохраняет camera feed, четыре персонажа, эффекты, Great, 15–20 секунд.
- [ ] PLAY AGAIN действительно сбрасывает миссии.
- [ ] FREE PLAY принимает любые карточки в любом порядке, с повторными реакциями.

## Parent / offline / performance

- [ ] Верхний правый угол 3 секунды + PARENT 2 секунды; короткий tap не открывает настройки.
- [ ] Camera/marker/audio tests, quality, reset, skip, force работают.
- [ ] Debug появляется только в активном Parent Mode; Exit его скрывает.
- [ ] `/offline-status`: после первого production load и reload все категории READY.
- [ ] Wi-Fi и cellular выключены; Home Screen relaunch загружает игру и локальную озвучку.
- [ ] Offline camera / CAT / DOG / LION работают без запроса к стороннему сервису.
- [ ] 10–15 минут игры, несколько resets и Free Play: Safari не закрывает страницу.
- [ ] При низком FPS AUTO снижает качество; LOW проверен на самом старом устройстве.
- [ ] Background / foreground не завершает все сцены за кадром; resume остаётся понятным.
- [ ] GPU/JS memory при повторных запусках стабилизируется; записать memory warning/reload, если есть.
