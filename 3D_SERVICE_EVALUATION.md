# Сервисы для новой основы Milo

Проверено 01.10.2026 по официальным страницам. Это сравнение возможностей,
а не результаты генерации Milo: в этих сервисах новая модель ещё не создана,
покупок и расходования платных кредитов не было.

## Выбор для сравнительного теста

Первым кандидатом считаю **Rodin / Hyper3D**: работа с несколькими ракурсами
и управление сеткой подходят для поиска более цельной основы Milo.
**Tripo** — второй кандидат, особенно для проверки автоматического рига.
Это оценка по документированным функциям; качество конкретного Milo нужно
сравнить на реальных экспортированных моделях.

| Вариант | Что подтверждено | Роль в нашем проекте |
| --- | --- | --- |
| RealityCapture / RealityScan | Восстановление по фотографиям и лазерным сканам | Подойдёт для физической фигурки, сфотографированной с разных сторон. Для нашего листа концепта выбираю генератор image-to-3D. |
| Polycam AI 3D Generator | Одна картинка, PNG/JPEG, три бесплатные генерации в Web | Возможна быстрая проба одного отдельного изображения Milo. Коллаж из трёх котят не загружать как один объект. |
| Rodin / Hyper3D | Несколько изображений одного объекта; варианты Quad/Raw и ограничения числа граней | Сравнить форму головы, шеи, корпуса, лап и худи по согласованным ракурсам. |
| Tripo | Генерация по изображениям; проверка совместимости рига, biped/quadruped и другие типы; GLB/FBX | Milo стоит на двух лапах: проверять biped и положение суставов, а не выбирать quadruped только потому, что это кот. |
| Sloyd | Image-to-3D, мультиракурсы, риг и анимация; GLB/OBJ/FBX | Дополнительный кандидат для единого состава персонажей. У платного Plus заявлены собственный стиль и коммерческое использование. |

Источники:

- [RealityScan](https://www.realityscan.com/) — назначение сканирования.
- [Polycam: создание по изображению](https://learn.poly.cam/hc/en-us/articles/35116894902292-How-to-Create-a-Model-from-the-3D-Generator).
- [Rodin: API нескольких изображений и сетки](https://docs.hyper3d.ai/en/api-specification/rodin-gen1-1-5).
- [Tripo: риг](https://developers.tripo3d.ai/en/docs/animations-rig).
- [Sloyd: функции и тарифы](https://www.sloyd.ai/pricing).

## Права и стоимость для открытого проекта

В [условиях Tripo, 5.2](https://www.tripo3d.ai/terms) права Free и Paid
разделены; [официальная справка](https://www.tripo3d.ai/help/privacy-policy/how-to-use-tripo-models-commercially)
не предоставляет Free коммерческое использование. Бесплатную пробу нельзя
автоматически считать подходящей для публикации ассета проекта.

[Rodin Creator](https://hyper3d.ai/pricing) стоит $30 при помесячной оплате;
страница заявляет расширенный экспорт и использование. Перед включением
конкретного результата в открытый GitHub сохранить действующую лицензию
на этот результат: [условия Rodin](https://hyper3d.ai/legal/terms).

[Sloyd Plus](https://www.sloyd.ai/pricing) стоит $15 при помесячной оплате;
заявлены владение созданным результатом и коммерческое использование.
Бесплатный Guest обозначен как personal-use. Условия сторонней библиотеки
готовых CC BY моделей отличаются от условий собственной генерации.

## Как сравнить без потери очередного дня

1. Использовать оригинального Milo. Подготовить отдельные фронтальный,
   боковой и задний ракурсы **в одной позе**. Не смешивать A-позу с листом,
   где лапы опущены. Polycam принимает только одно изображение.
2. Сделать небольшую серию вариантов; сначала смотреть геометрию без цвета.
3. Отбрасывать вытянутую шею, слипшиеся лапы, пустые глазницы, нарушенную
   симметрию и деформированный ворот до затрат на материалы/риг.
4. Проверить экспорт, затем поднятую лапу, поворот головы и сгиб запястья.
5. Только удачную основу довести в Blender: отдельная одежда, глаза/веки/рот,
   лицевая анимация, веса, ткань/мех и семь игровых клипов.
6. Показать тот же GLB в WebGL со всех сторон. После утверждения CAT перенести
   систему на остальных животных согласно CHARACTER_PRODUCTION.md.

Наличие quad-сетки или кнопки auto-rig само по себе не подтверждает чистые
петли деформации, хорошую мимику или соответствие утверждённому образу.
