# Milo v9 — мех, вторичные движения и голос

Восемь существующих персонажей получили один общий проход полировки.
Исходные поверхности тела, UV, текстуры 1024 и семь клипов сохранены.
Изменены веса кожи ушей/хобота и ворс; никакие новые прототипные тела не добавлены.

## Что изменено

- Два ear-контроллера у каждого друга, у Ellie также два контроллера хобота.
  Теперь 23 кости, у ELEPHANT — 25. Мягкая вторичная анимация накладывается на
  существующие клипы; сон, радость, бег и взмах отличаются интенсивностью.
- Ворс короче и тоньше. Исключены тёмные швы атласа на светлом мехе, у PANDA
  сохранены естественные тёмные уши/лапы. У Ellie волоски значительно короче.
- Рот реагирует на RMS реальной записанной реплики через WebAudio analyser.
  Персонаж определяется по cue; общие инструкции произносит Foxy. Это
  артикуляция по амплитуде, без фонем. На TV она реагирует на звук самого TV.
- Телефоны/iPad автоматически используют LOW groom, сохраняя исходную
  геометрию/карты. Галерея измеряет FPS и использует общий режим качества/DPR;
  LOW в игре также уменьшает ворс.
- Удалены sparse morph NORMAL-векторы с компонентами не более 1e-6. Это
  численный шум, не упрощение геометрии. Позиции, изображения и каналы
  анимаций не изменяются этим шагом. Общий набор: 47 316 200 байт (~45,1 MiB),
  примерно на 11% меньше предыдущего набора; CAT: 5 531 668 байт вместо 6 934 716.

## Восстановление

`scripts/polish-cast.py` открывает предыдущие `.blend` из
`.deployment/incoming-milo` и `.deployment/incoming-cast`, повторно использует
точные карты предыдущих публичных GLB, строит общий ворс, добавляет skin-контроллеры
и экспортирует в `.deployment/cast-polish`. Исходные `.blend` не перезаписываются.
`scripts/compact-morph-normals.py` уплотняет GLB. Для продолжения без приватных
сцен импортировать актуальный публичный GLB; точные файлы/хеши — в каталоге.

```powershell
blender --background --python scripts/polish-cast.py
node scripts/catalog-cast.mjs
npm run build
python scripts/check-cast-assets.py
python scripts/check-cat-studio.py
node scripts/check-cast-runtime.mjs
```

Предыдущий CAT v8 сохранён для сравнения/старых клиентов. Новые ассеты имеют
хешированные URL и используют исправленный runtime cache. Старые файлы на ISP
не удаляются. Инструкция TV: [TV_GUIDE.md](TV_GUIDE.md).

## Проверки и оставшиеся задачи

Проверены декодирование восьми GLB, веса, исходные семь движений, настоящая
деформация поверхности ушей/хобота, 32 кадра поз. Записанный голос CAT двигает
его рот и не двигает рот DOG. Пройдены 24 теста приложения и 14 TV-проверок.

Остались окончательная художественная оценка складок/век/мордочек, полноценные
фонемы и прослушивание голосов. Физические Safari/iPhone и телевизор недоступны
для автоматической приёмки: FPS, память, бумажные карточки и пульт требуют
проверки на устройстве. Новые игры по-прежнему отложены.

Опубликовано на ISP: по HTTPS сверены все восемь GLB, index, SW, страница
обновления и печатные карточки. Снимки конфигурации до/после подтвердили,
что DNS, сертификаты, настройки ISP и другие сайты не изменились.
История MindAR и offline relaunch также прошли 16 browser-проверок.
