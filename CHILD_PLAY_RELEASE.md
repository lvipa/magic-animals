# Поиск всей команды и английский с друзьями — 02.10.2026

## Как играть

- `/hunt`: найди восемь бумажных карточек Milo v2 в любом порядке. Альбом показывает найденных друзей. Для каждого есть задание на слух: послушать, выбрать действие и посмотреть, как друг его выполняет. За правильный ответ даётся звезда. Повторная карточка не добавляет лишние звёзды. Ошибка допускает повтор без штрафа. Альбом и задания сохраняются на этом устройстве. Под альбомом всегда доступна кнопка «Начать поиск заново», в том числе до нахождения всех друзей. Она сбрасывает друзей и звёзды текущего раунда, сохраняя мир и TV-сопряжение. В режиме камеры убери прежнюю карточку и покажи любую снова; камера остаётся включённой. Верхний счётчик и альбом показывают один и тот же прогресс раунда.
- Камера недоступна — можно выбрать «Без камеры» и искать друзей кнопками. Это режим 3D, а не результат распознавания бумаги.
- `/friends`: выбрать друга, коснуться его или нажать действие. Ребёнок слышит английскую фразу, видит движение и перевод, затем может повторить. Есть задания «найди друга» / «выбери действие», повтор реплики, дружеское объятие и рассказ о характерных частях тела.
- `/worlds`: полянка, лес, космос с ракетой, батуты. Выбор сохраняется и используется в 3D-комнате и на TV. В AR фон — живая камера; выбранный мир не закрывает карточку.
- Нижнее детское меню: домой, карточки, друзья, миры, TV. Вход и пароль не нужны. Существующий Parent gate оставлен для настроек и диагностики.

Меню находится отдельным слоем в `document.body` выше камеры и WebGL, с большими областями
касания и учётом безопасной нижней зоны экрана. На коротком экране приветствие прокручивается:
кнопки PLAY, свободного сканирования и печати не зажаты под меню.

## Что изучаем

Happy, wave, jump, run, sleep, sing, tired, hungry, thirsty, sad. Примеры:
«I am jumping!», «I am running!», «I am sleeping.», «I am singing!», «I am tired.», «I am happy!».
Whiskers, paws, tail, ears, mane, trunk, long, round, fluffy, big, black, white.
Все восемь друзей озвучены разными голосами. Добавлено 98 записей; полный каталог — 202 MP3/WAV.
Это записанные реплики с мультяшной обработкой; пение — короткое «La, la, la», не музыкальная песня.
Генерация выполняется локально при сборке, камера и речь ребёнка не отправляются в сервисы. Проверки произношения ребёнка нет.

## Модели и анимация

Общий GLB/rig/материалы Milo сохранены. Для FOX и DOG выпущены новые immutable GLB v10:
исправлена привязка хвоста (5 284 / 3 006 вершин), сглажено поле деформации нижней челюсти,
уменьшена амплитуда открытия до 70% при сохранении полости и языка. Хвост собаки перестал
вытягиваться вместе с рукавом в вершине прыжка. Исходная закрытая форма лица и PBR-карты сохранены.
CAT и остальные шесть GLB не пересобирались.

Семь исходных клипов остаются. Sing использует happy с ритмичным движением головы/корпуса;
tired, hungry, thirsty, sad добавляют отдельные позы поверх idle. Это дополнения к общей
скелетной системе, а не новые записанные клипы в GLB. У hungry рука складывается к животику,
у thirsty одна лапка поднимается к мордочке. Рот по-прежнему следует амплитуде записи, не фонемам.
`src/characters/poseLayer.ts` хранит отдельно базовую позу клипа, процедурные дополнения
и показанную позу. Каждый кадр дополнения начинаются с базовой позы: наклоны головы/корпуса,
IK лап и морфы лица не накапливаются, даже когда Three.js не перезаписывает постоянный трек.
Переключения всех действий, включая прерывание сна повторными касаниями, сглаживаются за 0,45 с.
План ручной художественной доработки поверхностей и одежды остаётся в MILO_POLISH_RELEASE.md.

Исходники исправлений: `scripts/repair-cast-deformations.py`; редактируемые сцены локально
в `.deployment/cast-polish/{foxy,dog}-repaired.blend` (в GitHub не входят).
Публичные GLB и код доступны в репозитории, секреты и файлы доступа исключены.

## Повторить сборку и проверки

Нужен Node >=22.12, затем `npm ci`, `npm run build`, `npm run preview`.
После запуска preview на 4173:

```text
node scripts/check-child-play.mjs
node scripts/check-mobile-controls.mjs --webkit
node scripts/check-character-transitions.mjs
node scripts/check-ar-roster.mjs --hunt
node scripts/check-cast-runtime.mjs
node scripts/check-pwa-update.mjs
node scripts/test-tv.mjs
python scripts/check-audio-cast.py
python scripts/check-cast-assets.py
```

Дополнительные записи: `python scripts/expand-audio-lines.py`, затем Python из
окружения Kokoro: `scripts/generate-neural-audio.py --only-new`. Он дополняет существующий
каталог, сохраняя старые реплики и эффекты. Модель и виртуальное окружение не включены в GitHub;
уже готовые записи находятся в public/audio и не требуют генерации для запуска игры.

Проверка AR использует синтетический MediaStream и настоящий MindAR в desktop Chrome.
Мобильные проверки используют касания, короткие экраны и смену ориентации в desktop
Chromium/WebKit. Проверка переходов проигрывает новые эмоции по 20 секунд на каждом
из восьми настоящих GLB-ригов, затем выход из сна и серию быстрых переключений.
Это не заменяет Safari на физическом iPhone с его панелями браузера.
Скриншоты поз и телефонного размера — `.test-artifacts/cast` и `.test-artifacts/child-play`.
Физическая бумага, Safari на iPhone и настоящий телевизор требуют отдельной проверки.
Новые рисунки мира — SVG/CSS-фон: это декорации; ракета не отдельный пилотируемый объект,
батут не физический симулятор. Новые сюжетные игры из FUTURE_WORK_HANDOFF.md ещё не реализованы.
