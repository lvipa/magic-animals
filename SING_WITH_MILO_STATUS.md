# Sing With Milo — полные песни и игровые сцены, 04.10.2026

## Запуск

- Музыкальный сайт: https://sing.flowlabli.online/.
- В Animals: https://animals.flowlabli.online/sing.
- Локально: Node.js 22.12+, `npm ci`, подготовка аудио из README, `npm run dev`, открыть `/sing`.
- Для TV локально: `npm run tv` (Vite проксирует сервер на 8080).
- Production: `npm run build`; отдельная музыкальная главная — `VITE_GAME_ENTRY=sing` перед сборкой.

Начальный экран — крупные картинки песен. Внутри песни: большая кнопка «Петь / Пауза»,
«Сначала», игровые картинки. Повтор строки и «Спел!» доступны у аудиопесен.
Сложные настройки и микрофон находятся в закрытом разделе «Для взрослых».
Статус переносится по ширине экрана; полноэкранная кнопка занимает одну иконку.
Награда — за участие, без оценки произношения и нот.

Полные официальные видео воспроизводятся в видимом плеере YouTube с обычными контролами.
Нужен доступ к YouTube; возможны ограничения платформы и реклама. При недоступности есть
понятное сообщение и ссылка на официальный источник. Видео не скачиваются, звук не извлекается.
В этой версии нельзя включить для них режимы «Повтори» и «Без вокала».
Игра располагается отдельно от видео и не закрывает его управление.
Время берётся из официального плеера. Жесты/переходы куплетов имеют приблизительные метки;
это игровое сопровождение, не точное караоке всех слов видео.

Twinkle и ABC используют полные исходные вокальные записи с их собственным аккомпанементом,
без пересинтеза, изменения темпа и второй фонограммы поверх. Инструментальный концерт —
отдельное полное исполнение того же музыканта с собственной длительностью.
Метки слов получены автоматическим выравниванием; нужна музыкальная проверка.

## Персонажи и качество

CAT/Milo и RABBIT/Poppy получили цветные и нормальные текстуры 2048×2048 из пользовательских
исходных GLB вместо 1024×1024. Сохранены прежние цветовые правки, геометрия, риг, морфы и клипы.
Новые модели имеют новые хеши в URL: CAT 8,29 МБ, Poppy 7,19 МБ. Старые модели сохранены.
Экран песни использует MSAA, до 2× supersampling и анизотропию до 8×.
Бюджет ограничен 4K; при низком FPS снижаются разрешение и плотность ворса.
Это улучшает текстуры и рендер, но не добавляет новую геометрию лица или полноценный мех киноуровня.
Жесты хлопков и частей тела используют существующий риг, IK и плавное смешивание поз.

## Микрофон

Включается вручную для аудиопесен: «Для взрослых → Повтори → Включить микрофон».
Измеряется только громкость в тихом окне ответа. Голос не записывается, не отправляется,
не хранится; слова и ноты не распознаются. Смена песни, уход и сворачивание останавливают
запись и музыку. Без микрофона есть «Спел!».

## Телевизор

1. На TV открыть https://sing.flowlabli.online/tv и нажать **START TV**.
2. Телефоном сканировать QR или открыть `/connect-tv` и ввести шестизначный TV-код.
3. На телефоне открыть «Песни», выбрать песню и нажать «Петь!».

TV показывает 3D сцену, выбранные игровые действия и подсказки. **Музыкальный звук и официальное
видео остаются на телефоне.** Передача музыкального звука на TV пока следующий этап.
Пауза, длительность и выбор действия восстанавливаются при перезагрузке TV.
Для сайтов используются отдельные приватные файлы TV-сессий.

## Архитектура и восстановление

| Файл | Назначение |
|---|---|
| `src/singing/catalog.json` | Семь песен, тайминг, разрешённые источники и официальные video ID |
| `src/singing/legacyCatalog.json` | Совместимость подключённого TV со старыми v3 уроками |
| `src/singing/SongPlayer.ts` | AudioContext clock; загрузка/декодирование только выбранной дорожки |
| `src/singing/VideoSongPlayer.ts` | Официальный iframe API, реальная длительность, пауза/seek и отмена загрузки |
| `src/singing/OfficialSongVideo.tsx` | Видимый официальный плеер и сообщение о недоступности |
| `src/singing/activities.ts`, `MusicActivity.tsx` | Игровые действия и крупные кнопки |
| `src/singing/SingPage.tsx` | Выбор песни, участие, настройки и TV heartbeat |
| `src/singing/SingStage.tsx` | Общая 3D сцена, космос/ферма/автобус/движения/паучок |
| `src/singing/TVSingScene.tsx` | Визуальное отображение общего состояния на TV |
| `scripts/prepare-song-library.py` | Полные разрешённые записи → нормализация и MP3 |
| `scripts/upgrade-character-textures.py` | Восстановление исходных 2K текстур на существующем риге |
| `public/music/song-limits.json` | Единые границы Node/PHP TV relay |

MP3 исключены из GitHub согласно условиям использования Pixabay: после клонирования
подготовить их скриптом из README. Они применяются внутри интерактивной игры.
Видео используют только официальные embeds. URL источников и авторы доступны взрослым.
Новые MP3 скачиваются по выбору песни и кешируются после загрузки, не задерживая установку PWA.
Текстуры/модели также скачиваются по выбору. Официальные видео офлайн не работают.
Секреты ISP/SSH не входят в репозиторий; публикация затрагивает только файлы двух разрешённых сайтов,
с резервной копией, проверкой хешей, PHP syntax и аудитом настроек DNS/сертификатов/других сайтов.

## Проверки и ограничения

Публикация 04.10.2026 завершена на обоих сайтах. HTTPS SHA256 подтвердил текущие
HTML/SW, полные MP3 и обе HD-модели. Живой PHP relay проверен для всех семи песен:
сопряжение, режимы аудиопесен, длительность/действия видеопесен и отклонение неверных звёзд.
Первый запрос сразу после замены PHP ещё увидел прежний обработчик; повторная проверка
после обновления кеша PHP прошла на обоих доменах. Настройки сервера не менялись.
Аудит до/после подтвердил сохранность DNS, сертификатов, настроек и файлов других сайтов.
Резервные копии этой публикации: `.deployment/full-song-v4-rollback/` (локально, не в GitHub).
Код игры сохранён в коммите `473abeb`, ветка `codex/milo-blender-handoff`.
TypeScript/ESLint, 36 модульных тестов, проверка восьми ригов, существующий TV-протокол
и браузерный сценарий обеих production-сборок прошли.

`npm test`, `npm run lint`, `npm run build`, `python scripts/check-cast-assets.py`.
`npm run test:singing` — production Chromium 390×844: семь песен, полный слышимый MP3-сигнал,
пауза/звёзды/повтор, освобождение микрофона, TV pairing/reload и игровые действия.

не подтверждение реального внешнего воспроизведения или качества звука.
Прямую проверку YouTube ограничивает текущий сетевой доступ. Физические iPhone/TV,
прослушивание и точность жестов нужно проверить с ребёнком отдельно.
