# Sing With Milo — первый уровень, 04.10.2026

## Запуск

Адрес после публикации: https://animals.flowlabli.online/sing.
В приложении: нижнее меню **Песни** или кнопка **ПЕТЬ С MILO** на главной.

Локально: Node.js 22.12+ (в этом workspace используется встроенный Node 24),
`npm ci`, `npm run dev`, открыть адрес Vite с путём `/sing`.
Для TV локально также запустить `npm run tv`: Vite проксирует `/tv-socket` на порт 8080.
Сборка: `npm run build`. Ни аккаунта, ни пароля ребёнку не требуется.

## Игровая петля

Один куплет Twinkle, Twinkle, Little Star; CAT/Milo; космическая сцена.

- **Пой вместе:** вокал и музыкальное сопровождение, 26 секунд.
- **Повтори:** шесть коротких образцов по 4 секунды; после каждого —
  7,5 секунды тишины для ответа ребёнка; весь круг — 72 секунды.
- **Мой концерт:** сопровождение без вокала; голос подсказки можно включить.
- Английские слова подсвечиваются по музыкальному времени. Есть перевод,
  картинка смысла и отдельное слово: star, wonder, high, sky, little, twinkle.
- **Спел!** и тап по текущей звезде дают награду за участие.
- Пауза, повтор текущей строки, новый круг, завершение концерта и локальный
  счётчик концертов. За пропущенную строку нет наказания.

Это первый уровень для совместной проверки с ребёнком. Поющая демозапись
ещё не является окончательным голосом Milo. Нужно прослушать её на телефоне,
согласовать тембр и затем записать качественный оригинальный певческий голос.
Обработка исходного пения не превращает его в студийную запись.

## Микрофон

Включается только вручную через **Для взрослых → Включить микрофон**.
Реагирует на уровень звука только в тихом окне ответа режима «Повтори».
Никакого распознавания слов, оценки нот, записи, отправки или хранения голоса.
При уходе со страницы и сворачивании вкладки потоки микрофона закрываются,
музыка останавливается. Без доступа к микрофону работают все режимы и «Спел!».

## Телевизор

1. На TV открыть https://animals.flowlabli.online/tv и нажать **START TV**.
2. На телефоне сканировать QR или открыть `/connect-tv` и ввести TV-код.
3. На телефоне выбрать **Песни**, режим и **Петь!**.

Milo, караоке и звёзды выводятся на TV. Управление и **звук песни в этой
версии остаются на телефоне**. Выбранный в обычной игре маршрут озвучки TV
пока не переносит музыкальную фонограмму. Это явно указано в настройках игры.
Пауза и состояние песни восстанавливаются после перезагрузки TV.
Обычная игра восстанавливается при переходе из песен в «Друзья» или «Карточки».

Улучшение качества TV: включено аппаратное сглаживание, supersampling до 1,5×,
буфер ограничен размером 4K. На мощном браузере большой экран больше не
принуждает модель к упрощённому ворсу. SmartTV и слабые устройства сохраняют
облегчённый ворс. Разрешение не исправляет исходную геометрию/текстуры модели;
визуальную разницу нужно проверить на физическом телевизоре.

## Архитектура

| Файл | Назначение |
|---|---|
| `src/singing/song.ts` | Текст, тайминг слов, режимы, фазы, проверка TV-состояния |
| `src/singing/SongPlayer.ts` | Два MP3-стема, общий AudioContext-clock, пауза/seek |
| `src/singing/Microphone.ts` | Локальный анализ громкости, управление потоком |
| `src/singing/SingPage.tsx` | Игровая петля, участие, настройки, TV heartbeat |
| `src/singing/SingStage.tsx` | Сцена CAT, караоке, звёзды, рот от вокального анализатора |
| `src/singing/TVSingScene.tsx` | Экран TV по серверному времени; рот имеет примерную анимацию |
| `src/scenes/DisplayResolution.tsx` | Ограниченный по размеру качественный рендер |
| `public/music/twinkle-v1/` | Вокал, сопровождение, сведения о правах и обработке |
| `scripts/generate-twinkle.py` | Воспроизводимая подготовка аудио |

Новый TV event `SING_SCENE` валидируется в Node и standalone PHP relay.
Команды не принимают произвольные URL/аудиофайлы. Состояние сохраняется в
комнате для восстановления TV. Старые AR-карточки, модели и TV-код сохранены.
MP3-стемы и страница включены в текущий PWA offline-пакет; модель CAT
кешируется после первого скачивания.

## Проверки

Публикация на ISP выполнена: 10 файлов, публичные SHA256 `index.html`, `sw.js`
и обоих MP3 совпали со сборкой. Конфигурация остальных сайтов, DNS,
сертификаты и их контрольные файлы совпали до/после публикации.
На живом сайте проверены запуск музыки, загрузка CAT и пауза без ошибок JS.
Standalone PHP relay проверен отдельно: сопряжение, передача состояния пения
и отклонение неверных звёзд. Резервные копии предыдущих entrypoints сохранены
локально в `.deployment/singing-rollback/` (не публикуются в GitHub).

`npm test` — фазы, тихие окна, повтор строки, неверные TV-команды и остальные
тесты приложения. `npm run lint`, `npm run build`.

`npm run test:singing` — production-сборка, Chromium, touch viewport 390×844,
пауза, звёзды, fake microphone, освобождение потока, завершение, restart,
TV pairing, восстановление после reload и возврат к Animals.
Скриншоты/результаты находятся в игнорируемом `artifacts/singing/`.
При необходимости `CHROME_PATH` указывает на совместимый Chromium.
`node scripts/test-tv.mjs --protocol-only` и `node scripts/test-poll.mjs`
проверяют сохранность существующих функций TV.

Физические iPhone/iPad/TV, слышимое качество пения и удобство для ребёнка
нужно проверить отдельно. Тест с fake microphone этого не подтверждает.
