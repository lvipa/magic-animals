# Sing With Milo — библиотека песен, 04.10.2026

## Запуск

Отдельный музыкальный сайт: https://sing.flowlabli.online/.
Версия внутри Animals также обновляется: https://animals.flowlabli.online/sing.
В приложении: нижнее меню **Песни** или кнопка **ПЕТЬ С MILO** на главной.

Локально: Node.js 22.12+ (в этом workspace используется встроенный Node 24),
`npm ci`, `npm run dev`, открыть адрес Vite с путём `/sing`.
Для TV локально также запустить `npm run tv`: Vite проксирует `/tv-socket` на порт 8080.
Сборка: `npm run build`. Ни аккаунта, ни пароля ребёнку не требуется.
Для отдельного музыкального сайта перед сборкой установить
`VITE_GAME_ENTRY=sing`. На нём главная страница сразу открывает музыку;
название страницы/PWA — Sing with Milo. В обычной сборке Animals главная
страница остаётся прежней. Новый поддомен использует отдельный ISP docroot,
сертификат и приватный файл TV-сессий.

## Игровая петля

Три коротких уровня с CAT/Milo: Twinkle, Twinkle, Little Star (космос),
ABC Song (буквы) и Itsy Bitsy Spider (полянка, паучок, дождь и солнце).

- **Пой вместе:** готовое исполнение с оригинальным аккомпанементом:
  Twinkle — 45 секунд, ABC — 25,12 секунды, Spider — 35,22 секунды.
- **Повтори:** образец строки, затем тихое окно не короче самой строки;
  длительность зависит от песни. Шесть строк у Twinkle/ABC, четыре у Spider.
- **Без вокала:** отдельное инструментальное исполнение того же музыканта.
  Оно имеет собственный темп и тайминг. Кнопка «Вернуть пение» переводит
  в вокальный режим и начинает песню сначала.
- Английские слова подсвечиваются по музыкальному времени. Есть перевод,
  картинка смысла и отдельное слово: star, wonder, high, sky, little, twinkle.
- **Спел!** и тап по текущей звезде дают награду за участие.
- Пауза, повтор текущей строки, новый круг, завершение концерта и локальный
  счётчик концертов. За пропущенную строку нет наказания.

Это рабочие уроки для совместной проверки с ребёнком. Сейчас поёт Mike Cole,
а не актёр оригинального Milo. Выбранный родителем ориентир — Jackie Cusic:
https://kolibelnie-pesni.com/media/twinkle-twinkle-little-star.
Эта конкретная фонограмма не включена в поставку: разрешение на её публикацию
не подтверждено. Ссылка сохранена в информации для взрослых.

## Микрофон

Включается только вручную через **Для взрослых → Включить микрофон**.
Реагирует на уровень звука только в тихом окне ответа режима «Повтори».
Никакого распознавания слов, оценки нот, записи, отправки или хранения голоса.
При уходе со страницы и сворачивании вкладки потоки микрофона закрываются,
музыка останавливается. Без доступа к микрофону работают все режимы и «Спел!».

## Телевизор

1. На TV открыть https://sing.flowlabli.online/tv и нажать **START TV**.
2. На телефоне сканировать QR или открыть `/connect-tv` и ввести TV-код.
3. На телефоне выбрать **Песни**, режим и **Петь!**.

Milo, караоке и звёзды выводятся на TV. Управление и **звук песни в этой
версии остаются на телефоне**. Выбранный в обычной игре маршрут озвучки TV
пока не переносит музыкальную фонограмму. Это явно указано в настройках игры.
Пауза и состояние песни восстанавливаются после перезагрузки TV.
Обычная игра восстанавливается при переходе из песен в «Друзья» или «Карточки».

Улучшение качества TV: включено аппаратное сглаживание, supersampling до 1,5×,
буфер ограничен размером 4K. На мощном браузере большой экран больше не
принуждает модель к упрощённому ворсу. SmartTV и слабые устройства сохраняют
облегчённый ворс. Разрешение не исправляет исходную геометрию/текстуры модели;
визуальную разницу нужно проверить на физическом телевизоре.

## Архитектура

| Файл | Назначение |
|---|---|
| `src/singing/song.ts` | Текст, тайминг слов, режимы, фазы, проверка TV-состояния |
| `src/singing/SongPlayer.ts` | Два MP3-стема, общий AudioContext-clock, пауза/seek |
| `src/singing/Microphone.ts` | Локальный анализ громкости, управление потоком |
| `src/singing/SingPage.tsx` | Игровая петля, участие, настройки, TV heartbeat |
| `src/singing/SingStage.tsx` | Сцена CAT, караоке, звёзды, рот от вокального анализатора |
| `src/singing/TVSingScene.tsx` | Экран TV по серверному времени; рот имеет примерную анимацию |
| `src/scenes/DisplayResolution.tsx` | Ограниченный по размеру качественный рендер |
| `public/music/twinkle-v2-natural/` | Естественный вокал, сопровождение, сведения о правах |
| `scripts/generate-twinkle.py` | Воспроизводимая подготовка аудио |
| `src/singing/catalog.json` | Три песни, реальные временные метки слов, источники записей |
| `public/music/studio-v3/` | Готовое пение с музыкой, отдельные инструментальные версии и credits |
| `scripts/prepare-song-library.py` | Загрузка разрешённых записей, короткий фрагмент, громкость и экспорт |
| `public/music/song-limits.json` | Единые ограничения песен для Node/PHP TV relay |

Новый TV event `SING_SCENE` валидируется в Node и standalone PHP relay.
Команды не принимают произвольные URL/аудиофайлы. Состояние сохраняется в
комнате для восстановления TV. Старые AR-карточки, модели и TV-код сохранены.
MP3-стемы и страница включены в текущий PWA offline-пакет; модель CAT
кешируется после первого скачивания.

## Текущие записи и права

Mike Cole / matthewmikemusic публикует эти записи под Pixabay Content License.
Страницы исполнений и исходные URL приведены в каталоге и в `credits.json`
каждой песни. Ведущая дорожка — цельная запись вокала вместе с её оригинальной
музыкой. Второе сопровождение в этом режиме отключено. Вокал не пересинтезируется,
его высота и темп не меняются. Обработка: короткий фрагмент, секунда перед началом,
короткое затухание в конце, нормализация громкости и MP3.

MP3 исключены из GitHub и восстанавливаются скриптом подготовки библиотеки;
разрешено применение в интерактивной игре, а не отдельная раздача аудиопакета.
Для чистой копии сначала выполните шаг подготовки из README.
Метки вокальных слов выровнены по записи; инструментальный концерт — другой
аранжировочный вариант, его метки приблизительные и требуют музыкальной проверки.
Браузерная проверка подтверждает наличие сигнала и выбор дорожки, а не
субъективное качество исполнения. Не заявлять, что записи были прослушаны человеком.

## История первого прототипа v1/v2

Первый куплет Jane Taylor (1806), традиционная мелодия.
Исходное пение: Derrick Coetzee / Dcoetzee, **CC0 1.0**.
[Страница источника](https://commons.wikimedia.org/wiki/File:Twinkle_Twinkle_Little_Star_-_sung_with_full_lyrics.ogg).
После замечания пользователя о роботизированном звучании v1 отключены
изменение формантов, коррекция высоты и пересинтез голоса. В v2 сохранены
исходный темп, интонация, дыхание и тембр человеческого исполнения. Извлечён
куплет, добавлена секунда тишины перед началом, нормализована громкость и
закодирован MP3. Корреляция исходного и подготовленного PCM вокала = 1,0
(до MP3; изменена только общая громкость). Тайминг караоке и аккомпанемент
приведены к исходной записи. Это не студийный финальный голос Milo.
Новое синтезированное сопровождение Magic Animals также предоставлено как CC0.
SHA256 исходника и все изменения перечислены в `credits.json`.
Новые MP3 имеют новые URL `twinkle-v2-natural`: браузер не должен брать
старый роботизированный вариант из кеша. V1 сохранена как исторический ассет.
Для будущих песен проверять права на композицию и на выбранную запись отдельно.
