# CAT — пересмотр производства, 29.09.2026

## Phase 0: фактическое состояние до изменений

Движок: Three.js 0.160.1; сцены React Three Fiber 8.17 и компоненты drei.
Миграция движка не требуется: существующий стек поддерживает SkinnedMesh,
PBR, GLB, skeletal clips и morph targets. Проблема находится в ассете.

| Область | Реализация до перестройки |
| --- | --- |
| Остальные животные | `toyFactory.ts`: SphereGeometry, TorusGeometry, TubeGeometry и отдельные Object3D |
| CAT | GLB из `build-cat-studio.py`: 79 отдельных сеток; голова/лапки/манжеты/уши в основном независимые параметрические поверхности |
| Загрузка | GLTFLoader + локальный DRACOLoader; SkeletonUtils.clone; загрузка перед React mount |
| Материалы | Principled→glTF PBR, sheen/clearcoat; 6 PNG карт; runtime envMapIntensity |
| Анимации | AnimationMixer, 7 NLA clips, переход 0.2 секунды |
| Rig | 22 кости; body/head, отдельные elbow/knee; один жёсткий tail bone |
| Skin weights | Большинство объектов rigid; sleeve и trouser leg смешивают два веса по высоте |
| Свет | Локальная PMREM RoomEnvironment, key/fill/rim; ContactShadows только в галерее |
| Камера | Галерея: FOV 33°, OrbitControls с вращением/приближением, без pan; игра FOV 40° |
| Мобильный бюджет | DPR 1/1.5/2, падение ниже 25 FPS включает LOW; gallery DPR до 1.5; облегчённый groom для общего состава/TV |
| Ограничения | WebGL на iOS/Android/TV; нет измеренного мобильного FPS; физический тест отложен пользователем |

GLB, Blender-файл и скелет сами по себе не означают готовый production asset.
Предыдущая версия не удовлетворяет требованиям к геометрии, капюшону и деформации.

## Решение

Прежний генератор геометрии CAT выводится из активного производства. Новая
контрольная сетка должна иметь соединённые плечи/рукава, непрерывные переходы
череп→шея→тело, ноги и лапы; одежда — отдельную поверхность с толщиной,
открытым горлом/манжетами, объёмным капюшоном, швами и складками.
Рабочий источник — редактируемая Blender-сцена, GLB — её экспорт.
Это не миграция приложения и не улучшение старых отдельных примитивов.

Проверки нового источника должны оценивать связность, нормализованные веса,
геометрию в восьми направлениях и все семь действий. Старый критерий
«не меньше 35 meshes» удаляется: количество отдельных частей не мера качества.

Целевой бюджет кандидата: до 80 тысяч треугольников в одной модели, до 24
draw calls для самого CAT, текстуры до 1024, GLB до 8 MB. Это рабочий бюджет,
а не утверждение о достигнутых 30–60 FPS на телефоне.

## Граница текущего этапа

Только CAT. UI, задания, управление камерой, QR и TV протокол сохраняются.
FOX и остальные виды не меняются. Общая производственная архитектура для
всего состава вводится после визуального утверждения CAT; копирование CAT mesh
с заменой цвета и ушей не является планом производства других видов.

Результат этой итерации — проверяемый кандидат, исходник и отчёт. Его нельзя
назвать утверждённым или соответствующим всем художественным критериям,
пока это не подтверждено просмотром и пользователем.
