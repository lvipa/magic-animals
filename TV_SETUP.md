# Игра на телевизоре

## Запуск

Из корня проекта: `npm install`, `npm run build`, `npm run tv`. На этом Windows-компьютере:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 build
powershell -ExecutionPolicy Bypass -File .\run.ps1 tv
```

Локальная проверка: http://localhost:8080/tv. Для камеры iPad нужен доверенный HTTPS/WSS (DEPLOYMENT.md). На обоих экранах откройте один и тот же origin relay, доступный обоим устройствам. Production preview на 4173 сам не содержит relay.

## Подключение

1. TV браузер → `/tv` → START TV. Стрелки пульта перемещают фокус, Enter нажимает кнопку.
2. iPad/телефон → наведите штатную камеру на QR телевизора и откройте ссылку. Код уже заполнен; нажмите **Connect TV**.
3. Для ручного ввода: тот же сайт → **Connect TV · QR / code** на стартовом экране, либо адрес `/connect-tv`. Введите шестизначный код с TV, вернитесь в игру и нажмите PLAY. Родительский режим для подключения больше не требуется.
4. Показывайте карточки: TV получает сцены, животных, финал и передачи через портал.
5. Голос по умолчанию на iPad. Для TV выберите Speak on TV в Connect TV. После reload телевизора нажмите Enable sound.

При недоступном WebGL предусмотрены простые изображения животных. Reload восстанавливает сессию вкладки и последнюю сцену. Потеря связи отменяет незавершённую передачу. New code создаёт новую комнату; Disconnect TV завершает pairing. Комнаты в RAM удаляются после двух часов бездействия; перезапуск сервера требует нового кода.

На публичном ISP работает PHP polling relay с приватным JSON state вместо Node.
Физическая проверка чтения QR камерой телефона/TV остаётся пользовательским тестом.
Для собственного PHP hosting задайте `MAGIC_ANIMALS_TV_STATE_PATH` абсолютным путём
к файлу вне document root, с правом записи у процесса PHP; разместите скрипт как
`tv-poll.php` рядом с собранным приложением и `audio/manifest.json`.

Передаются игровые ID/состояния, камера/видео не передаются. TV требует сети между экранами и доступного relay. После кэширования внешний интернет не нужен при локальном relay с доверенным TLS. Физический тест iPad + TV отложен по просьбе пользователя. `npm run test:tv` проверяет временный relay и два desktop-браузера.
