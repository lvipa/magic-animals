# Milo и восемь AR-карточек — 01.10.2026

## Как играть

На первом экране **SCAN ANY CARD · 8 friends** сразу запускает свободное
сканирование. Показывайте одну карточку целиком в любом порядке: CAT, DOG,
LION, FOX, RABBIT, BEAR, PANDA, ELEPHANT. Счётчик показывает найденных друзей
из восьми. **PLAY** сохраняет озвученную историю CAT → DOG → LION.
При отказе в доступе к камере доступен явный выбор игры без камеры.

Печать: `/printables/cards.html`, PDF `/printables/magic-animals-milo-a4.pdf`
(три листа A4, 100%), исходники `/printables/magic-animals-print-sources.zip`.
Используйте новые карточки v2. Прежние три рисунка оставлены как архивные
файлы, но новый набор распознавания использует обновлённые карточки.

## CAT

В игру подключён присланный пользователем Milo с общим 21-костным скелетом,
семью клипами, отдельными глазами, веками, промежуточным морганием, полостью
рта, языком и `mouthOpen` / `smile`. Это замена старого процедурного CAT.
Материал тела стал матовым; короткие изогнутые пряди на шерстяных участках
повторяют веса скелета и окраску исходной текстуры. HIGH содержит 1200 лент,
LOW — 420; одновременно отображается один слой. Это мобильная имитация
короткой шерсти, без симуляции волос.

Точный файл, SHA-256 и метрики — `public/models/cat-master-info.json`.
`src/characters/catAsset.ts` содержит URL GLB с хэшем в имени, чтобы старая
PWA не подставляла прежнего кота. GLB меньше 8 MB, текстуры не больше 1024²,
геометрия сжата Draco. Исходная детальная поверхность сохранена: в файле
128 076 треугольников вместе с двумя слоями шерсти. Измерение FPS/памяти
на физическом iPhone остаётся необходимым.

Редактируемый источник текущей поставки находится локально в
`.deployment/incoming-milo/milo-game-short-fur.blend`. Он не содержит доступов,
но вместе с личными входными файлами не добавлен в Git. Для новой сборки
`scripts/export-milo-game.py` читает локальный `milo-animation-study-WIP.blend`
и создаёт GLB, метаданные и `catAsset.ts`. Приложение из GitHub запускается
с готовым GLB, Blender для запуска не требуется.

Дальнейшая художественная приёмка CAT ещё нужна: макушка/щёки, уголки век,
веса одежды и некоторые движения требуют полировки. Остальные семь 3D-моделей
сохраняют прежний вид до утверждения эталона CAT; их карточки уже используют
общие согласованные концепты Milo. Обновление карточек не означает, что весь
3D-состав переведён на новый rig.

## Распознавание и размещение

`scripts/marker-roster.mjs` задаёт стабильный порядок восьми целей.
`src/config/animals.ts` использует те же индексы 0–7. Файлы v2 находятся
в `public/markers/milo-v2/`. Полные изображения компилируются MindAR 1.2.5;
`marker-matching.mjs` оставляет для начального совпадения только признаки
уникальных боковых узоров и пересобирает их кластеры. Общие рамки, надписи
и похожие худи не используются для идентификации. Tracking и центр якоря
сохраняют координаты всей карточки. Проверка тестирует каждую картинку
против всех семи чужих индексов.

AR создаёт модель при первом распознавании и не анимирует скрытые модели.
Общее фото-финал и TV используют `useCastLayout`: два столбца на узком экране,
до четырёх на широком. CAT в финале смотрит вперёд и радуется; прежнее вращение
спиной заменено. Родительский режим, QR / шестизначный TV-код сохранены.

## Воспроизведение

```sh
npm ci
npm run cards
npm run targets
python scripts/package-printables.py  # Python + reportlab
npm run test:tracking
npm test
npm run lint
npm run build
python scripts/check-cat-studio.py
npm run preview -- --port 4173
node scripts/check-ar-roster.mjs
node scripts/browser-test.mjs
node scripts/test-tv.mjs
```

`check-ar-roster.mjs` подаёт синтетический MediaStream настоящему MindAR и
проверяет смену восьми целей в порядке ELEPHANT → PANDA → CAT → RABBIT → FOX →
DOG → BEAR → LION на экране 390×844. Это desktop Chrome, не физический Safari.
PDF проверяется после рендера всех трёх страниц. Секреты ISP/SSH не публикуются.

Публикация: ассеты сначала, затем `index.html`, последним `sw.js`; загрузка
через временный файл и атомарное переименование. Старые ассеты остаются
доступными для открытых вкладок. Конфигурация ISP и соседние сайты сверяются
до и после; для этой поставки изменение настроек ISP не требуется.

## Выполненные проверки этой поставки

- TypeScript, ESLint, production build; 23 unit-теста игры и один тест
  освобождения rig без уничтожения общей геометрии/материалов.
- Восемь настоящих MindAR-проверок на масштабированных и повёрнутых карточках;
  ни одна не совпала с семью чужими индексами.
- Восемь последовательных AR-переключений через синтетический MediaStream,
  счётчик 8/8, экран 390×844.
- 16 browser-проверок: разрешение/отказ камеры, три главы, Free Play,
  освобождение camera stream, precache, offline reload и отсутствие upload кадров.
- 14 TV-проверок: соединение, все восемь сцен, восстановление, transfer,
  декодирование 104 аудиофайлов и реальные два браузерных экрана.
- Финал на 390×844: четыре друга в двух рядах, видны целиком.
- GLB: 21 сустав, семь различающихся движений, morph tracks, два LOD шерсти,
  цвет вершин, MASK-прозрачность и фактический размер встроенных текстур до 1024².
- PDF: отрендерены и визуально проверены три листа A4.

Физический iPhone/iPad/TV этим набором проверок не заменён.
